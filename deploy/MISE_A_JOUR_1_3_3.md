# Version 1.3.3 (9) : accès aux bilans et profils

- Dans Matchs, toute la tuile ouvre l'historique face à l'adversaire. Une ligne « Voir le bilan face à… » avec un chevron indique cette action. Le vote et le suivi de participation gardent leurs propres boutons.
- Les classements général, mensuel, saison et statistiques proposent « Voir le profil » avec un chevron sur chaque joueur.
- Sur l'accueil, le logo du club et son libellé « Bilan » ouvrent le bilan total : matchs, victoires, nuls, défaites, buts marqués, encaissés et différence, avec l'historique.

Les bilans couvrent toutes les saisons et équipes enregistrées. Ils incluent les matchs joués avec un score complet, même si le vote est ouvert ou rouvert, et excluent les matchs à venir et de test. Un match supprimé disparaît automatiquement du bilan. Les anciens matchs sans identifiant adverse sont rattachés par leur nom.

Publier les changements Git pour redéployer Vercel. Pour Android, distribuer une nouvelle version selon la procédure de signature habituelle. Vérifier **1.3.3 (9)** depuis le profil.

Aucune mise à jour du VPS ou des règles Firestore n'est nécessaire.
